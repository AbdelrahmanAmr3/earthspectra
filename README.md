**EarthSpectra** is a Python package for remote sensing data analysis of multispectral and hyperspectral imagery.  
It is designed to provide data loaders for different Earth observation sensors, spectral analysis utilities, visualization tools, band conversions, and multi-sensor workflows.

> 🚧 **Under Development**  
> EarthSpectra is currently under active development. The first stable release is coming soon.

## Overview

EarthSpectra aims to make it easier to work with spectral remote sensing data from different sensors, including hyperspectral and multispectral missions such as **Tanager-1**, **Landsat**, **Sentinel-2**, and more.

The package will support common workflows for loading, analyzing, visualizing, and converting spectral data across multiple sensors.

## Planned Features

- Data loaders for different multispectral and hyperspectral sensors
- Support for sensors such as Tanager-1, Landsat, Sentinel-2, and future missions
- Spectral band conversion and harmonization tools
- Spectral response function utilities
- Visualization tools for spectral signatures and imagery
- Remote sensing data analysis workflows
- Utilities for multi-sensor comparison and integration
- Clean and user-friendly Python API
